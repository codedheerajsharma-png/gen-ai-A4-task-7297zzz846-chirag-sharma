# Gen AI A4
## Overview
This project processes sales and product data using Python in a Jupyter Notebook.
<img width="541" height="190" alt="image" src="https://github.com/user-attachments/assets/00ca48ea-8f4d-4c98-9ad6-d02df660fed0" />

## Files
genai_file1.ipynb - Main notebook
sales_data.txt - Sales data
products.txt - Product information
discounted_report.txt - Generated report
## How to Run
Download or clone this repository.
Open genai_file1.ipynb in VS Code.
Make sure sales_data.txt and products.txt are in the same folder.
Run all notebook cells.
The notebook generates discounted_report.txt.
